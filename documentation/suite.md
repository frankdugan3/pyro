# Pyro Suite

There's a full suite of libraries that build on the foundation Pyro provides:

- [Pyro](https://github.com/frankdugan3/pyro) - Compose extensible, framework-agnostic components in Elixir. Built-in support for Phoenix LiveView and Hologram.
- [PyroComponents](https://github.com/frankdugan3/pyro_components) - Ready-made design and framework-agnostic components built with Pyro. Built-in support for Phoenix LiveView and Hologram.
- [PyroManiac](https://github.com/frankdugan3/pyro_maniac) - Declarative, framework-agnostic UI for Ash resources. Automatically render with PyroComponents.
